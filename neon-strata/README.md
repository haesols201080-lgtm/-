# NEON STRATA — 빛의 제국

하늘이 닫힌 뒤 햇빛이 화폐가 된 도시 **카이로스-9**. 구름 아래 침전층의 캡슐 한 칸에서 시작해 광편을 줍고, 하늘길로 배달을 뛰고, 구역 간 시세 차익을 먹고, 사업체와 기업을 인수해 구름 위 **왕관**까지 올라가는 SF 오픈월드 게임입니다. Three.js(WebGL2)만으로 동작하며 빌드 과정이 없습니다.

## 실행

```bash
cd neon-strata
node tools/server.mjs 8765     # 정적 서버
# 브라우저에서 http://localhost:8765/
```

ES 모듈과 폰트를 불러오므로 `file://` 로는 열 수 없고 정적 서버가 필요합니다(아무 정적 서버나 가능). `?q=low|medium|high|ultra` 로 품질을 강제할 수 있고, 게임 안 `Tab → 설정` 에서도 바꿉니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 (화면 클릭으로 마우스 고정) |
| Shift | 달리기 · 비행 부스트 |
| Space / C | 점프 · 상승 / 하강 |
| F / R | 스키머 탑승·하차 / 호출 |
| E / Q | 상호작용 · 승강기 위 / 아래 |
| Tab (M) | 관리 패널: 일감 · 거래 · 사업 · 주식 · 차고/면허 · 서열 · 설정 |

터치 기기에서는 왼쪽 가상 스틱, 오른쪽 드래그 시점, 화면 버튼(상승·하강·부스트·탑승·호출·E·Q·메뉴)이 나타납니다. 진행은 localStorage에 자동 저장되고, 자리를 비운 동안의 사업 수익도 정산됩니다.

## 게임 루프 — 럭스 경제

1. **광편 줍기** → 2. **배달 의뢰**(도보 → 스키머) → 3. **구역 간 차익거래**(구역마다 생산/수요가 달라 시세가 다르고, 속보 이벤트로 출렁임)
→ 4. **사업체 인수·확장**(초당 수익) → 5. **에테르 거래소**에서 기업 지분 51% 인수(해당 구역 수익 2배) → 6. **왕관** 인수와 광휘 서열 1위.

고도는 계급입니다. **고도 면허**를 올려야 더 높이 날 수 있고, 3급부터 구름(930–1260 m)을 뚫고 스파이어 꼭대기 **제니스**(1,500 m)에 오를 수 있습니다. 스파이어 아트리움의 승강기로도 끊김 없이 올라갑니다.

## 도시

- 중앙의 **스파이어**(속이 빈 아트리움, 스카이 도크, 제니스 덱)를 축으로 8개 구역이 방사형으로 자란 구조: 침전층 · 파운드리 · 에테르 항 · 구시가 · 메리디안 · 루미나 · 하이브 · 버던트.
- 간선(대로·순환로) → 2차 가로망 → **블록 → 필지** 순으로 계획하고 건물은 반드시 자기 필지 안에만 지어지므로 서로 겹치지 않습니다(`city.audit()` 로 검사).
- 건물은 구역별 문법으로 생성됩니다: 상가주택·연립·기술 타워(슬래브/원통/비틀림/테이퍼/게이트/쌍둥이/적층/육각 다발/원반/쐐기/테라스 등)·메가타워(다발/바늘/지구라트)·캡슐 메가블록·길드하우스·기록 첨탑·공장·항만 창고·수직 농장.
- 타워 로비, 상점, 플레이어의 캡슐 숙소는 실제 문을 통해 걸어 들어가는 **내부 공간**입니다(로딩 없음).
- **거리의 삶** — 1층 상점은 업종(식당·상점·기술·의원/미용)을 가지며, 간판·유리 너머의 실내(진열대, 주방 창구와 메뉴판, 스크린 벽, 손님과 점원)·가게 앞 집기(테이블과 의자, 입간판, 진열대, 배달 로봇)가 모두 업종에 맞춰집니다. 주거동에는 캐노피와 우편함이 있는 출입구와 실제 깊이가 있는 주차장 입구가 있습니다.
- 인도에는 걷는 사람 외에 가게 앞에 앉아 있거나 서서 통화·대화하는 사람들이 있고, 도로에는 주차된 호버카·스쿠터, 횡단보도, 전신주 전선, 전광 안내 갠트리가, 머리 위로는 택배 드론 항로와 대로 위 초대형 홀로그램 광고가 지나갑니다.

## 기술

- `src/render` — 높이 안개·볼류메트릭 구름·갓레이·SSAO·블룸·필름 톤매핑 포스트 파이프라인, GPU에서 구운 PBR 재질 배열, 리세스 창문 + 인테리어 매핑 파사드 셰이더(층/세대 단위 조명 로직), 네온 라이트 필드, 간판 아틀라스.
- **조명** — 도시의 모든 간판·가로등·실내등은 실제 점광원입니다. `lightgrid.js` 가 수만 개의 광원을 월드 XZ 격자(셀당 최대 8개, 광원 1개 = RGBA16UI 텍셀 1개)에 담고 표면 셰이더가 픽셀마다 순회해 벽·노면을 비추고 젖은 아스팔트에 GGX 하이라이트를 만듭니다. 셀이 넘치면 가장 약한 광원의 도달 반경을 줄여 셀 경계 이음매가 생기지 않습니다. 여기에 화면 공간 반사(SSR), 원거리용 라이트 필드(도시 광해·구름 하부 반사광), 원경 점광(항공장애등·외곽 가로등)이 더해집니다.
- `src/world` — 도시 계획(`plan.js`), 파사드 툴킷, 건물 레시피, 내부 공간, 초거대 구조물, 인스턴스 소품.
- `src/fx` — GPU 경로 텍스처 기반 교통, 비·증기·불꽃, 절차적 스킨 인체와 보행 애니메이션 베이크, 군중.
- `src/game` — 물리(캐릭터·비행체), 플레이어/카메라/승강기, 경제와 임무, 오디오. `src/ui` — HUD와 관리 패널.
- `tools/shot.mjs` — 헤드리스 Chromium(소프트웨어 GL)으로 화면을 캡처해 검증하는 스크립트. `tools/build-fonts.py` — 간판/UI 폰트 서브셋 생성.

글꼴은 SIL OFL 1.1 폰트(Black Han Sans, Do Hyeon, Jua, Nanum Myeongjo, Nanum Brush Script, Noto Sans KR, Orbitron, Rajdhani)의 서브셋이며, three.js는 MIT 라이선스입니다.
