# 세렌 설계서

## 1. 한 줄
소리로 중력을 다루는 문명이 사는 위성에 떨어진 인간이, 그들의 말을 노래로 배우고, 잠든 탑을 깨우고, 끝내 자기 노래를 하늘에 보내는 이야기 — 그리고 그 노래가 남는 세계.

## 2. 남기고 싶은 감정 (여운)
- **이해받는 경험**: 처음 들은 말(「오라, 작은 별. 우리는 오래 기다렸어.」)은 글자로만 보입니다. 글자돌을 읽고, 아웬의 혼잣말을 듣고, 단어가 하나씩 쌓이면 어느 순간 그 첫 말이 한국어로 열립니다. 게임은 이 순간을 카드로 따로 보여 줍니다.
- **남는 울림**: 플레이어가 지은 여섯 음은 저장되고, 이후 밤의 음악과 아웬의 합창에 섞여 나옵니다. "내 노래가 이 세계에 남았다"는 느낌.
- **작음과 넓음**: 1.7 km 높이의 척추, 하늘의 4분의 1을 덮는 우르, 머리 위를 가로지르는 고리, 200 m 짜리 하늘고래 — 인간은 작고 세계는 크지만 적대적이지 않습니다. 기다려 주는 세계.
- **안녕 대신 「다시」**: 아웬에게는 작별 인사가 없습니다. 「다시 울리자」. 게임을 이어할 때 나오는 첫 알림도 이 말입니다.

## 3. 세계의 논리 → 플레이
| 세계의 논리 | 플레이로 드러나는 방식 |
|---|---|
| 세렌의 핵이 우르의 조석에 울린다(「울림」) | 공명이 강한 곳(깨어난 탑 근처)은 중력이 약해져 더 높이 뛰고 오래 난다 |
| 아웬은 노래로 물질을 다룬다 | 공명기의 다섯 음이 세계와 상호작용한다. 수정은 소리를 기억했다 음속만큼 늦게 되돌려 보낸다 |
| 노래가 섬을 띄운다 | 탑이 침묵하자 떠돌섬이 협곡 바닥에 내려앉았다 → 탑을 깨우면 섬이 다시 떠오른다 |
| 아웬의 글자는 악보 | 글자의 점 높이 = 음 높이. 글자를 보고 노래를 읽을 수 있다 |
| 해류는 공명의 길 | 탑을 깨우면 척추에서 그 지역으로 가는 해류가 다시 흐른다(이동망이 넓어짐) |
| 우르에 조석 고정 | 우르는 늘 북쪽 하늘 같은 자리 = 길잡이. 밤에는 보름처럼 차서 땅을 호박색으로 비춘다. 계절이 기울면 한낮에 일식 |
| 늙은 아웬은 울림이 된다 | 메아리(옛 기억)는 「열림」으로 열리는 빛. 숲의 빛은 떠난 이들의 숨결 |

## 4. 지도
대륙 반경 약 15 km + 남동쪽 군도. 북쪽(−Z)에 우르.
- **척추 고원** (0, 0) — 해발 390 m 고원 위 수도 하모네아와 척추(전망대 해발 약 1690 m, 승강줄 30 km).
- **빛갈대 들판** (남) — 시작 지역. 추락 지점, 이슬터 마을, 노래하는 공명탑(튜토리얼).
- **유리 황야** (동) — 분홍 유리 사구, 메사, 노래수정. 수정 도시 윤슬.
- **균사 숲** (서) — 거대 빛버섯. 갓마을.
- **부유 협곡** (북동) — 계단형 붉은 지층과 협곡. 떠돌섬.
- **서리 첨봉** (북서) — 1,700~2,000 m 산맥. 별듣는 탑. 탑이 잠든 동안 눈보라(안개)가 짙다.
- **노래하는 바다** (남동) — 섬과 바다 아치. 물노래.
경계 26 km 밖은 「장막」 — 더 나아갈 수 없음.

## 5. 핵심 행동
1. **이동** — 지상(8.2 m/s, 달리기 12.5) / 점프 / 활공(에너지 보존형: 급강하로 속도, 당기면 고도) / 썰매(최대 34, 가속 50 m/s, 내리막 가속, 물 위) / 해류(70~100 m/s) / 승강 기둥 / 상승 기류.
2. **공명** — 다섯 음. 솟음(공중 추가 상승), 열림(메아리), 흐름(전방 가속), 빛(빛 구슬·빛나방), 고요(고래 부르기·진정).
3. **듣기와 배우기** — 대화·혼잣말·글자돌·도감·메아리·부탁 보상으로 단어 학습. 들은 말 기록이 다시 번역됨.
4. **깨우기** — 공명탑의 선율 따라 부르기(깨운 수에 따라 3~7음). 깨우면 색이 물결처럼 돌아오고 해류·기류·중력·섬이 바뀜.

## 6. 끝없는 구조
- **본편**(mq0~mq5): 낙하 → 첫 말 → 흩어진 썰매 → 척추의 도시 → 잠든 탑들(3) → 대답(이름 노래) → 온 합창(5) → 축제. 끝난 뒤에도 같은 세계에서 계속.
- **날마다 부탁**: 게임 속 하루(20분)마다 템플릿에서 1~2개 생성. 보상 별씨 + 모르는 단어 하나.
- **주기적 사건**: 일식(5일 주기), 별비(밤마다 45%), 고래의 노래, 축제의 밤.
- **수집**: 단어 73, 메아리 12, 글자돌 34, 도감 11, 지도 안개, 장비 강화 8단계.
- **확장 지점**: 새 지역·장소(places.js), 새 해류(currents.js), 새 퀘스트·대화(story.js), 새 부탁 템플릿(world-events.js), 새 동작(actions.js).

## 7. 아트 방향
- 회화적인 저폴리 + 강한 대기 원근. 모든 셰이더가 같은 하늘색 안개 함수(높이 안개)를 공유해서 수십 km 너머까지 공기층이 이어진다.
- 팔레트: 청록·보라·복숭아·금. 낮 하늘은 청록, 노을은 자홍, 밤은 남보라 + 우르의 호박빛.
- 생물발광: 밤이 되면 땅의 결, 갈대 끝, 버섯 갓, 아웬의 목소리 띠가 빛난다(블룸).
- 행성 곡률을 정점 셰이더로 적용(반경 1,600 km 상당)해 높은 곳에서 수평선이 둥글게 보인다.

## 8. 소리
- 모든 소리는 Web Audio 합성(파일 없음). D 장조 5음 음계 — 공명 음과 음악이 언제나 어울림.
- 공명 음: FM 종소리 + 유리잔 배음 + 4초 잔향. 아웬의 말: 삼각파 + 모음 필터 + 비브라토로 미끄러지듯 부르는 노래.
- 생성 음악: 장소·시간(낮·밤·일식·침묵)에 따라 화음 진행과 겹이 바뀜. 이름 노래가 있으면 밤에 섞여 나옴.
