# 개발 일지

## v0.1 — 첫 판 (2026-10-01)

### 구현된 것
- **엔진**: three.js r186, esbuild 로 한 파일 빌드. 하늘 장면 → 세계 장면 2단 그리기, ACES 톤매핑, 언리얼 블룸(보통 이상), 동적 해상도.
- **지형**: 쿼드트리 LOD(64 m ~ 65 km), 워커에서 청크 생성, 치마(skirt)로 틈 가림, 정점색(지역 팔레트·지층·눈·모래톱)과 생물발광 결, 물속 흡수·거품, 행성 곡률.
- **하늘**: 시간대 팔레트(밤·노을·낮·일식), 별·은하수·오로라·새털구름, 가스행성 우르(띠·폭풍의 눈·위상·고리 그림자·일식 테두리), 우르의 고리, 아웬의 궤도 고리(행성 그림자), 승강줄 윗부분, 구름 무리.
- **시계**: 하루 20분, 5일 계절 주기, 계절마다 한낮 일식(일식 중 시간이 느려짐), 밤에는 보름 우르의 호박빛.
- **식생**: 3층 흩뿌리기(풀 16 m 패치 / 덤불 48 m / 나무 128 m / 거대 식물 512 m), 지역별 모델 18종, 바람·플레이어에 눕는 풀, 배치 셀 묶음으로 그리기 횟수 절감, 거대 식물 LOD.
- **구조물**: 척추(갈비 6개·고리 2개·심장·바늘·전망대·승강차), 하모네아(첨탑·돔·떠 있는 꽃잎·디딤돌), 이슬터, 공명탑 6(침묵/노래 상태), 승강 기둥 5, 조망점 6, 옛 관문, 윤슬(수정 도시·프리즘 심장), 갓마을(거대 버섯 위 마을·다리), 떠돌섬(탑을 깨우면 떠오르는 섬 9개), 별듣는 탑, 물노래(바다 아치·물 위 꽃잎).
- **이동**: 지상·점프(코요테·버퍼)·활공(에너지 보존)·썰매·수영·해류·승강·상승 기류·약한 중력 구역, 2.5D 충돌(원기둥·상자·경사로·움직이는 발판).
- **아웬**: 절차적 모델(메시 5개), 이름 있는 인물 9명 + 거리의 아웬 52명(배회·밤에 모여 노래·혼잣말).
- **언어**: 73단어, 악보 글자(SVG), 들은 말 기록·재번역, 추정 학습, 첫 말 이해 순간 카드.
- **공명**: 다섯 음과 효과, 수정 메아리(음속 지연), 공명탑 선율 퍼즐, 이름 노래 짓기·보내기 연출.
- **퀘스트**: 본편 6장 + 곁이야기 1 + 날마다 부탁(템플릿 5종), 단계 자동 확인, 목표 빛기둥·나침반 표시.
- **발견**: 글자돌 34, 메아리 12, 조망점(카메라 연출 + 지도 밝히기), 장소·지역 발견, 도감 11, 별비·별씨·장비 강화.
- **UI**: 타이틀(실시간 풍경), 오프닝 자막, HUD(목표·나침반·알림·모아 자막·공명 단추), 대화창(글자/번역), 카드, 지도(음영 지도·안개·표식), 일지(이야기·단어·들은 말·메아리·도감·기록), 설정(품질·소리·감도·쉬기), 터치 조작(가상 스틱·버튼), 게임패드.
- **소리**: 전부 합성 — 공명 음, 아웬의 노래하는 말, 바람·썰매 웅웅, 발소리, 효과음, 생성 음악(낮·밤·일식·침묵), 고래의 노래.
- **저장**: localStorage 자동 저장(30초·중요 순간·창 닫을 때), 버전·이전 처리.

### 중요한 결정
- **한 파일 배포**: 사용자가 파일 하나로 플레이할 수 있게 빌드 결과(`index.html`)를 커밋한다.
- **모든 높이를 함수 하나로**: 렌더·충돌·배치가 어긋나지 않게.
- **하늘을 별도 장면으로**: 우르·고리는 무한히 멀고, 세계 깊이 정밀도는 지키기 위해.
- **색 대신 공기**: 모든 셰이더가 같은 안개(=하늘색)를 공유해 거리감을 만든다. 낮 안개 밀도 약 8e-5/m, 높이 감쇠 1/1100 m.
- **조명 보정**: ACES 가 중간톤을 밝히므로 직접광·환경광을 0.56 배로 낮춤(색이 바래지 않게).
- **블룸 안전장치**: tonemapping 조각에 NaN/무한대 제거를 끼워 넣음(밤 장면이 통째로 검게 되던 문제).
- **세로 화면·가로 화면 모두**: 터치 UI 는 대화·메뉴·연출 중 숨김(`body.busy`).

## v0.1.1 — 손맛 다듬기 (2026-10-01)
- **입자** (`world/particles.js`): 점 900개 풀 하나로 착지 먼지·물보라·솟음 반짝임·썰매 물안개·해류 반짝임. 날개 끝 빛 궤적(`Trail`, 카메라를 향하는 리본).
- **날개** 다시 만듦(XY 평면 막 + 빛나는 살 + 끝점) — 뒤에서 볼 때 선으로만 보이던 문제.
- **스카프**: 움직이는 기준틀에서 verlet + 길이 강제(FTL) — 순간이동·고속에서 늘어나지 않음.
- **대화 카메라**: 말하는 인물과 주인공을 함께 잡는 어깨 너머 구도.
- **해류 관**: 카메라 가까이에서 흐려짐(타는 중 화면을 가리지 않게).
- **본편 뒤 목표**: 추적할 퀘스트가 없으면 HUD 에 첫 부탁을, 부탁도 없으면 「다시 울리자 — 메아리·글자돌 수·일식까지 남은 날」을 보여 준다. 부탁도 나침반·빛기둥 표시(안부·글자돌·빛 밝히기·해류).
- 추락 지점 메아리 빛을 줄이고 조금 떨어뜨림(첫 장면을 가리던 문제).

### 알려진 한계 / 다음 할 일
- 실제 기기(특히 저사양 모바일) 프레임 측정이 필요하다. 헤드리스 소프트웨어 렌더러로는 수치(삼각형·그리기 횟수)만 확인했다.
- 지형 그림자 없음(고정 해 방향 그림자맵이나 지평선 그림자를 고려).
- 강·호수 없음(바다 높이 하나). 고원 위 호수, 협곡의 강을 추가하면 좋다.
- 아웬 도시 내부(실내)는 없다. 집에 들어가는 연출, 장인 온의 작업장 등.
- 떠돌섬에 오를 길은 상승 기류뿐 — 섬 사이 해류를 추가하면 좋다.
- 긴다리·고래 외 생물(유리게·포자해파리·바다 리본)은 도감 항목만 있다.
- 서리 첨봉 눈보라는 안개만 짙어진다(눈 입자 없음).
- 번역 추정은 단순 확률(노출 4회 이상). 문맥 기반 추정으로 발전시킬 수 있다.
