# 테라 제네시스 (TERRA GENESIS)

외계 행성 「아르케」에 홀로 착륙해 직접 걸어 다니며 탐험하고, 현장에서 시설을 짓고, 대기를 바꿔 하늘·바다·숲을 만들고, 정착지에서 도시와 문명까지 키우는 3D 오픈월드 브라우저 게임입니다.

- 실행: `planet/index.html`을 브라우저로 엽니다. 파일로 직접 열어도 되고 정적 서버로 열어도 됩니다. 필요한 것은 `index.html`, `style.css`, `game.js`, `assets/` 네 가지입니다(three.js는 번들에 포함).
- 이어하기: 진행 상황은 브라우저 localStorage에 60초마다 자동 저장됩니다. 일시 정지 메뉴에서 바로 저장할 수도 있습니다.
- 개발자 모드: 주소 끝에 `?dev=1`을 붙이면 자원·연구·테라포밍 단계·시간·순간이동 패널이 나타납니다.

## 무엇을 하는 게임인가
1. **착륙**: 영하 63°C, 산소 없는 붉은 행성에서 시작합니다. 착륙 포드가 산소를 채워 주고, 주변의 빛나는 광석(철·규소·티타늄…)을 좌클릭으로 채집합니다.
2. **기지**: 포드에서 철판·유리를 만들고(Tab) 태양광 패널, 히터, 대기 드릴, 거주 모듈을 세웁니다(B). 시설은 가까운 발전기·송전탑과 전선으로 자동 연결됩니다.
3. **테라포밍**: 열·기압·산소·바이오매스가 더해진 테라포밍 지수(Ti)에 따라 행성이 단계적으로 바뀝니다. 단계는 25개입니다: 첫 온기 → 푸른 하늘 → 옅은 안개 → 구름 → 두꺼운 구름층 → 비 → 해빙 → 액체 물 → 웅덩이 → 호수 → 지의류 → 이끼 → 새싹 → 초원 → 꽃 → 숲 → 울창한 숲 → 곤충 → 만개 → 숨쉬는 대기 → 온화한 기후 → 생명의 행성 → 생태계 번성 → 완전한 테라포밍 → 두 번째 지구. 각 단계는 그 변화가 실제로 보이기 시작하는 지점에 놓여 있고, 하늘·물·생명은 단계 사이에서도 끊김 없이 조금씩 변합니다. 분지가 바다로 차오르고, 이끼와 풀, 나무가 퍼지고, 곤충과 새가 날아다닙니다.
4. **자동화**: 광맥 위의 자동 채굴기, 정련소·조립기, 드론 허브의 물류망(드론이 실제로 물건을 나름)으로 공장이 스스로 돌아갑니다.
5. **식민지와 문명**: 정착민은 저절로 오지 않습니다. 식민 본부(착륙장)와 심우주 교신기를 세우고, 하늘에 구름이 생길 만큼 테라포밍한 뒤 교신기(E)에서 초청 교신을 보내면 응답한 개척선의 셔틀이 내립니다. 테라포밍이 진행될수록 한 번에 응답하는 인원이 늘어납니다. 주거지에 물·식량·전력·배급소 같은 필요를 채우면 인구가 늘고, 개척민 → 기술자 → 공학자 → 시민으로 업그레이드되면서 집 모양도 바뀝니다. 연구로 시대를 넘어 전초기지 → 정착지 → 마을 → 도시 → 문명에 이르고, 마지막에는 궤도 엘리베이터를 세웁니다.
6. **탐험**: 16km 너비의 행성에는 극지 빙원, 크레이터 지대, 층암 메사와 대협곡, 모래 바다와 소금 평원, 현무암 화산대와 거대 순상화산, 결정 평원이 이어집니다. 추락선 잔해·보급 캡슐·고대 유적을 조사하면 재료와 연구 점수, 「유레카」를 얻습니다. 먼 곳은 탐사 로버(N)로 다닙니다.

## 조작
| 입력 | 동작 |
|---|---|
| WASD · Space · Shift | 이동 · 점프/제트팩(공중에서 유지) · 달리기 |
| 마우스 | 시점 (처음에 화면 클릭) |
| 좌클릭 | 채집 · 설치 |
| E | 상호작용 (건물 정보·보관함·침대·유적 조사·로버 탑승) |
| B / 1–9 | 건설 메뉴 / 핫바 건설 (메뉴에서 숫자 키로 핫바 등록) |
| 휠 · R · PageUp/PageDown | 회전 · 90° 회전 · 기초 판 높이 |
| F / G | 해체 모드 / 지형 도구 |
| Tab · J · M | 가방·제작 · 연구 · 지도 |
| V · L · N | 1인칭/3인칭 · 헬멧 조명 · 탐사 로버 |
| Esc / P | 일시 정지 · 설정 (그래픽 품질, 감도, FOV, 테라포밍 속도) |

## 개발
```bash
cd planet
npm install
npm run build   # game.js (minified, 워커 포함)
npm run dev     # 소스맵 포함 빌드
```
- 소스는 `src/`에 있습니다. `world/`(행성 생성·지형 LOD·하늘·식생·소품), `build/`(건물 모델·배치), `sim/`(경제·테라포밍·식민지·연구), `npc/`, `player/`, `ui/`, `game/`으로 나뉩니다.
- 지형은 Web Worker가 생성합니다. `build.mjs`가 워커를 문자열로 묶어 `game.js` 하나에 넣기 때문에 `file://`에서도 동작합니다.
- 레퍼런스 조사와 설계 반영 내용은 [docs/planet/research.md](../docs/planet/research.md)에 있습니다.
