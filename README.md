# 빌더즈 팩토리

드래곤 퀘스트 빌더즈의 진행 방식과 건축을 새티스팩토리의 공장 자동화와 합친 3D 복셀 브라우저 게임입니다. `index.html` 하나로 동작하고, 3D 렌더링은 three.js r128(cdnjs)을 씁니다. 파일을 브라우저로 열면 바로 플레이할 수 있어요(인터넷 연결 필요).

## 이야기
아주 먼 옛날, 아르테라 사람들은 무엇이든 만들 줄 알았고 하늘 너머 별에 닿는 「별의 사다리」까지 세웠습니다. 그러나 「멈춤의 왕」이 "아무것도 새로 만들지 마라"는 저주를 내리자 사람들은 만드는 법을 잊었고, 사다리는 무너졌으며, 대지는 몬스터의 차지가 되었습니다.

플레이어는 저주가 닿지 않은 마지막 빌더입니다. 무너진 사다리 잔해 옆에서 깨어나 피난민 소녀 리아를 만나고, 희망의 깃발을 꽂아 마을을 되살립니다. 이어 사다리의 마지막 기술자였던 리아 할아버지의 기술 수첩으로 공장을 일으키고, 멈춤의 왕의 군단을 막아 내며, 별의 사다리를 다시 세워 하늘로 「희망의 등불」을 보내 저주를 풉니다.

- 프롤로그 컷신(무너진 사다리 잔해), 장 시작·습격·보스·엔딩마다 이야기 장면이 나옵니다. 장면 중에는 게임이 멈추고, 건너뛰기를 할 수 있어요.
- 새 주민마다 자기 사연을 가지고 찾아옵니다. 대장장이의 딸, 상인, 늙은 석공, 발전소 기술자의 손자, 하늘을 꿈꾸는 소녀, 요리사가 있어요.
- 마일스톤은 「할아버지의 수첩」의 장으로 표현되고, 최종 보스는 멈춤의 왕입니다.

## 드퀘빌식 진행과 건축
- **희망의 깃발**: 깃발을 꽂은 곳이 마을 구역이 됩니다. 마을 레벨이 오를수록 구역이 넓어져요.
- **블록 건축**: 흙·돌·원목 같은 블록을 부수면 그 블록을 얻고, 다시 쌓을 수 있어요. 나무판자, 돌벽돌, 기와, 유리, 콘크리트, 철판 블록도 만들 수 있어요.
- **번뜩임**: 처음 얻은 재료가 새 레시피를 떠올리게 합니다.
- **방 레시피**: 2칸 높이 벽 + 문 + 횃불(모닥불)로 둘러싸면 방이 됩니다. 가구에 따라 침실·식당·작업실·작은 공장·발전실·창고가 되고, 방마다 효과가 있어요.
- **감사의 하트**: 방 완성, 주민 부탁, 침실에서 잔 아침, 식당 점심, 공장 납품으로 주민 머리 위에 하트가 생깁니다. 모아서 깃발에서 마을 레벨을 올리면 새 주민·레시피·설계도가 열려요.
- **주민 부탁**: 머리 위에 `!`가 뜬 주민과 대화하면 부탁을 받아요.
- **설계도**: 설계도를 놓고 마을 보관함에 재료를 넣어 두면, 주민들이 길을 찾아가 대신 지어 줍니다.
- **밤과 습격**: 밤에는 슬라임이 나오고, 이야기 중 습격 이벤트와 킹 슬라임 보스가 있어요. 막힌 몬스터는 벽을 부숴요.
- **4장 구성**: 희망의 깃발 → 불꽃의 공장 → 조립 라인 → 하늘로 가는 길.

## 새티스팩토리식 공장
- 광맥 노드 위에 놓는 채굴기, 컨베이어(Mk1/Mk2), 경사 컨베이어, 분배기, 제련기, 제작기, 조립기가 있어요.
- 바이오매스·석탄 발전기가 마을 전체 전력망을 공유하고, 전력이 부족하면 모든 기계가 느려집니다.
- 희망의 깃발이 HUB 역할도 해서 컨베이어로 부품을 받고 마일스톤 3단계를 진행해요.
- 최종 목표는 우주 엘리베이터에 부품을 채워 발사하는 것입니다.

## 조작
| 입력 | 동작 |
|---|---|
| 화면 클릭 | 마우스 고정 (Esc로 해제, 안 되면 커서 모드) |
| WASD · Space | 이동 · 점프 (한 칸 턱은 자동으로 넘어요) |
| 왼쪽 버튼 유지 | 부수기 · 공격 |
| 오른쪽 버튼 | 쌓기 · 열기 · 대화 · 잠자기 |
| 오른쪽 버튼 유지 + 시점 이동 | 컨베이어/블록 연속 설치 |
| R · 1–9 · 휠 · E · F · V | 회전 · 단축칸 · 가방 · 베리 먹기 · 시점 거리 |

터치 기기에서는 가상 스틱, 부수기/쌓기 모드, 회전, 가방, 시점, 점프 버튼이 나타나요. 진행 상황은 브라우저 localStorage에 60초마다 자동 저장됩니다.
