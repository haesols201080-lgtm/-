# 빌더즈 팩토리

드래곤 퀘스트 빌더즈의 마을 건설과 새티스팩토리의 공장 자동화를 섞은 브라우저 게임입니다. `index.html` 하나로 동작하며, 파일을 브라우저로 열면 바로 플레이할 수 있어요.

## 게임 흐름
- **빌더**: 나무·돌·광석을 캐고 작업대에서 제작합니다. 마을 구역(노란 점선) 안에 벽 + 문 + 횃불로 방을 만들면 마을 레벨이 오르고 주민이 찾아옵니다. 침대·작업대·기계·보관함에 따라 침실·작업실·공장·창고로 구분됩니다.
- **팩토리**: 광맥 위에 채굴기를 놓고 컨베이어로 제련기·제작기·조립기에 연결합니다. 발전기(나무/석탄)로 전력을 공급하고, 완성품을 HUB로 보내 마일스톤을 달성하면 새 기술이 열립니다.
- **밤**: 슬라임이 나타납니다. 횃불 근처는 비교적 안전하고, 주민들도 함께 싸워 줍니다. 방 안의 침대에서 자면 아침이 옵니다.
- **목표**: 마일스톤 4 「우주 엘리베이터」 완수.

## 조작
| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 왼쪽 버튼 유지 | 캐기 · 부수기 · 공격 |
| 오른쪽 버튼 | 설치 · 기계/HUB 열기 · 대화 · 잠자기 |
| 오른쪽 드래그 | 컨베이어/벽 연속 설치 (방향 자동) |
| R | 설치 방향 회전 |
| 1–9 / 휠 | 단축칸 선택 |
| E | 가방 · 제작 |
| F | 베리 먹기 |

터치 기기에서는 가상 스틱과 채굴/설치 모드 버튼이 나타납니다. 진행 상황은 브라우저 localStorage에 60초마다 자동 저장됩니다.
